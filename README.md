# siwoosdev-lab.github.io

GitHub Pages **사용자 사이트** 저장소 — 도메인 루트 `https://siwoosdev-lab.github.io/` 를 담당한다.

- `app-ads.txt` — AdMob 앱 인증용. 스토어의 개발자 웹사이트 도메인 **루트**에 있어야 해서
  프로젝트 사이트(`/nolly/…`)가 아니라 이 저장소에 둔다. 게시자 ID(`pub-2452431814631215`)
  하나로 널리의 모든 앱(iOS·Android)을 함께 인증한다. 앱을 추가해도 이 파일은 그대로다.
- `index.html` — 루트 접속을 널리 앱 안내 사이트(`/nolly/`)로 넘긴다.

앱별 개인정보처리방침·지원 페이지는 [nolly](https://github.com/siwoosdev-lab/nolly) 저장소에 있다.
